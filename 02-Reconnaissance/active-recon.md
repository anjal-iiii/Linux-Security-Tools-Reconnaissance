# Active Reconnaissance

## Objective

To understand active reconnaissance and basic network enumeration
in a controlled laboratory environment.

## Tools Used

- Nmap
- Ping
- IP
- SS

## Activities

- Host discovery
- Network information gathering
- Port enumeration
- Service identification

## Lab Environment

Testing is performed only on localhost or an authorized VirtualBox
laboratory system.

## Basic Commands

```bash
ip addr
ip route
ping -c 4 127.0.0.1
ss -tuln
