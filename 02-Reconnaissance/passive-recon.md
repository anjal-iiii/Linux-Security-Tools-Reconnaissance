# Passive Reconnaissance

## Objective

To understand how information can be collected without directly
interacting with a target system.

## Tools Used

- Dig
- Nslookup

## Activities

- DNS information gathering
- Domain information analysis
- DNS record identification

## Lab Target

example.com

## Commands

```bash
dig example.com
dig example.com A
dig example.com MX
dig example.com NS
nslookup example.com
